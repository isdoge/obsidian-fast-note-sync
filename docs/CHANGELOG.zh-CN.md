# 更新日志

## v2.5.0
> *2026/11/18*

条目末尾括号内为上游 issue / PR 编号：不带前缀的属于 `haierkeys/obsidian-fast-note-sync`，`服务端#` 属于 `haierkeys/fast-note-sync-service`。

### ✨ 新增

- **同步**: 远端删除的文件按 Obsidian「删除文件」偏好处理（系统回收站 / 库内 `.trash` / 永久删除），不再直接永久删除（#286）。
- **配置同步**: 支持同步插件子目录中的文本资源（如字典文件），自动排除 `node_modules` 等目录并限制大文件（#278）。
- **远端配置**: 移动端粘贴远端配置失败时区分剪贴板不可用、读取失败、配置无效，并可手动粘贴 JSON（#200）。

### 🚀 优化

- **同步**: 同步时间改为该类型全部完成且没有失败后才推进，停滞重启或下载失败漏掉的更新会在下一轮补拉（#282）。
- **同步**: 分页同步停滞时自动重启该轮同步，并带 5 / 10 / 20 分钟退避与次数上限（#285 #287）。
- **同步**: 长时间同步不再被超时打断；取消的队列与未确认的笔记可恢复（#280 #281）。
- **附件**: 附件分页去重、上传会话恢复有上限；下载会话停滞时判定失败并释放槽位，不再卡住整轮同步（#283 #284）。
- **附件**: 内容未变、只是修改时间变化的附件不再上传（#256）。
- **协议**: 部分环境 protobuf 解码失败时，本次连接自动退回 JSON 并只提示一次（#228）。
- **配置同步**: 只有 `main.js` / `manifest.json` / `styles.css` 变化才重载插件，`data.json` 同步不再让插件被停用再启用（#249 #269）。
- **界面**: 界面与调试输出中的硬编码中文改为多语言文案；错误详情保留在内部调试日志中（#274 #301）。

### 🛠️ 修复

- **同步**: 修复一轮同步进行期间，其它设备推送过来的实时变更（笔记、附件、配置、目录）被直接丢弃的问题，现在排队到本轮结束后处理。
- **同步**: 修复新建的空白笔记（如当日日记）覆盖服务端已有内容的问题（#205）。
- **同步**: 修复其它设备把文件改名或移动到本机尚不存在的目录时改名丢失、两端不一致的问题。
- **同步**: 修复远端删除把本地尚未同步的修改一并删掉的问题，本地有待上传改动或内容与基线不同时保留并重新上传（#277）。
- **同步**: 修复本地没有同步记录的文件（离线新建、外部程序生成）在重连后被远端删除记录删掉的问题，现在保留并重新上传（服务端#514 服务端#391）。
- **同步**: 修复冲突未解决的笔记继续上传并覆盖远端的问题（#276）。
- **同步**: 修复过期的下载结果覆盖本地新修改的问题（#295）。
- **同步**: 修复远端删除、改名可能作用到路径别名（大小写或 Unicode 归一化不同的另一个文件）的问题（#291）。
- **同步**: 修复文件监听竞态、WebSocket 鉴权失败、抢锁失败导致本地文件事件被静默丢弃的问题（#293）。
- **同步**: 修复父子目录并发删除报错的问题（#257）。
- **同步**: 修复路径含 Obsidian 不允许的字符（如半角冒号）的笔记无法落地且没有任何提示的问题，现在通知中显示原路径与原因（#271）。
- **只读模式**: 修复只读设备每次启动仍在服务端新建目录、仍响应配置上传请求的问题（#220 #275）。
- **云预览**: 修复首次同步不遵守云预览设置的问题；开启云预览时也会应用服务端的删除与修改时间更新（#292 #298）。

- **云预览**: 修复离线期间修改的附件重连后不上传的问题；上传中断不再被当作已上传，自动清理本地附件前会核对服务端内容（服务端#512）。
